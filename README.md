# milena-belaeva.ru

Сайт-визитка Милены Романовны Беляевой. Одна страница, без сборки: GitHub Pages отдаёт файлы из корня ветки `main`.

Тексты, параметры и контакты лежат в [`js/config.js`](js/config.js). После правки достаточно обновить файл в репозитории — вёрстку трогать не нужно.

## Параметры

Откройте `js/config.js`, объект `measurements`.

Пустая строка на сайте показывается как «—». Обычная строка одна и та же на обоих языках. Если подпись отличается, задайте объект `{ ru, en }` — так сделаны рост, волосы и глаза. Переключатель RU / EN берёт нужную строку сам.

```js
measurements: {
  height: { ru: "170 см", en: "170 cm" },
  bust: "80",
  waist: "60",
  hips: "88",
  size: "XS (40)",
  shoes: "37–38",
  hair: { ru: "Тёмно-каштановые", en: "Dark brown" },
  eyes: { ru: "Серо-голубые", en: "Blue-grey" },
},
```

`size` — размер одежды.

## Текст

Там же, в `js/config.js`. У полей ниже есть `ru` и `en`:

- `kicker` — строка над именем («Москва · готова к поездкам»)
- `subtitle` — подзаголовок под большим именем. Пустая строка скрывает строку
- `city` и `travel` — город и готовность к поездкам в карточке параметров
- `bio` — текст в блоке «О себе»
- `experience` — строка про школу VERONA
- `languages` — языки

## Контакты

Объект `contacts`. Пустое поле на страницу не попадает — ни в список, ни в меню. Почты сейчас нет, `email` оставлен пустым.

```js
contacts: {
  phone: "+7 977 428-82-50",
  telegram: "https://t.me/Mi_B25",       // или "@Mi_B25"
  instagram: "https://instagram.com/mi.belyaeva", // или "@mi.belyaeva"
  email: "",
},
```

Порядок на сайте: телефон, Telegram, Instagram, почта. Заполните только то, что нужно показать.

## Фотографии

Снимки лежат в `images/`. Оригиналы на несколько мегабайт в репозиторий не кладём: для каждого кадра сделаны JPEG и WebP шириной 800, 1400 и 2000 пикселей. Страница сама выбирает размер под экран.

Новое фото — это блок `<button class="shot">` в `index.html`.

1. Уменьшите кадр до 2000 пикселей по длинной стороне и сохраните JPEG хорошего качества. По желанию сделайте ещё версии 1400 и 800 и те же три размера в WebP — так страница останется быстрой на телефоне.
2. Положите файлы в `images/`. Удобно называть их одинаково: `new-800.jpg`, `new-1400.jpg`, `new-2000.jpg` и `.webp`.
3. Скопируйте любой `<button class="shot js-photo">` в нужную сетку в `index.html`:
   - `portfolio__grid` — два студийных кадра в жакете, по два в ряд (`sizes`: `50vw`);
   - `portfolio__trio` — чёрная серия и новогодняя съёмка, по три в ряд (`sizes`: `33vw`).
   На телефоне кадры идут друг под другом. В ряд лучше класть чётное число для пары и кратное трём для тройки, чтобы не оставалось пустой ячейки.
4. Замените пути, подписи `alt`, `data-alt-ru` и `data-alt-en`. В `data-full` укажите самый большой WebP: он открывается в лайтбоксе.

Если нет времени делать три размера, можно оставить один JPEG и упростить блок до одного `<img src="images/new.jpg" alt="...">` внутри кнопки. Лайтбокс, стрелки клавиатуры и свайп на телефоне заработают и так: в `data-full` и `data-fallback` поставьте этот же файл.

Крупный портрет в шапке — кнопка `hero__media`. Меняется так же: картинка и подпись. Сейчас это студийный кадр с рукой у подбородка. Ниже — пара в жакете, чёрная серия в три кадра и три новогодних.

## Как посмотреть локально

Из папки сайта:

```bash
python3 -m http.server 8080
```

Откройте `http://localhost:8080`.

## Домен и GitHub Pages

Файл `CNAME` уже содержит `milena-belaeva.ru`.

В репозитории: Settings → Pages → Branch `main`, папка `/ (root)`. В поле Custom domain будет `milena-belaeva.ru`. После того как сертификат выпустится, включите Enforce HTTPS.

У регистратора домена для корня `milena-belaeva.ru` нужны четыре A-записи на адреса, которые показывает GitHub в настройках Pages (сейчас это `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`). Если заводите `www`, для него — CNAME на `<username>.github.io`. Актуальные адреса лучше сверить с [документацией GitHub](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site).
